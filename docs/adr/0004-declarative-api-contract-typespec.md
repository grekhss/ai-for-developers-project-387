# Единый декларативный контракт API на TypeSpec

Контракт API был продублирован руками: `src/lib/meetings/types.ts` на фронте и структурная копия в `server/types.ts` (+ `Session` в `server/session.ts`, `LoginInput` в `server/validate.ts`), а серверные правила формата жили отдельно в `server/validate.ts`. Решили сделать источником истины `contract/main.tsp` (TypeSpec 1.11.x) и **генерировать** из него `contract/openapi.yaml` и две TS-копии — `src/lib/contract.gen.ts` и `server/contract.gen.ts`; ручные .ts-типы стали alias'ами на генерат. Контракт описывает формат и схему, **не домен**: `server/validate.ts` остаётся ручным.

> Toolchain-часть этого решения (генерируются только типы, клиент и `validate.ts` рукописные) уточнена и расширена в **ADR-0005**: генерируются и клиентский SDK, и серверные схемы, единой самопроверяющейся командой. Источник истины здесь остаётся в силе.

## Considered Options

- **TypeSpec** — выбран: декларативный язык с генерацией языко-нейтральной OpenAPI-спеки; типы для обеих сторон из одного вызова.
- **zod-схемы в общем модуле** — рантайм-валидация бесплатно, но нет языко-нейтрального артефакта и пришлось бы менять `rootDir: server` (ослабив инвариант «сервер не импортирует из `src/`»).
- **OpenAPI 3.1 YAML вручную** — проще тулчейн, но схема пишется на YAML руками, без типовой проверки контракта компилятором.

## Consequences

- **Две копии генерата, а не один общий файл**: сервер не может импортировать из `src/` (`rootDir: server`, ARCHITECTURE §9), поэтому генерация идёт в каждую сторону; идентичность копий проверяет тест.
- **Пин `~1.11.0`** — последняя линия TypeSpec под Node 20 (с 1.12 компилятор требует Node ≥22). Обновление возможно только вместе с Node.
- **`.npmrc` с `legacy-peer-deps=true`** — у `openapi-typescript@7` устаревший peer `typescript@^5.x` при TS 6 в проекте; генератор с TS 6 работает (проверено генерацией), но флаг глушит peer-проверки для всего дерева.
- **`contract:check` в `npm run check`** — генерирует во временный каталог и сравнивает с закоммиченными артефактами; устаревший или правленный руками `.gen.ts` не проходит гейт.
- Дубли контракта больше не появляются: новые типы добавляются в `contract/main.tsp` и приезжают на обе стороны через `npm run contract`.
